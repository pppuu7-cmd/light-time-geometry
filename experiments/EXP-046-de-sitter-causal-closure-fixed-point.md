# EXP-046 — de Sitter causal closure and parameter-free fixed-point ratios

## Objective

Continue the global-causal novelty gate from EXP-044 and the pressure-response branch from EXP-045.

Ask whether a global causal fixed point can remove free dimensionless parameters.

The candidate closure is the de Sitter causal state:

\[
\dot H=0,
\qquad
H=H_* >0,
\qquad
L=H_*^{-1},
\qquad
p_{\rm eff}=-\rho_{\rm eff}.
\]

The test asks whether this condition fixes:

\[
HL,
\qquad
c,
\qquad
\Gamma/H.
\]

---

## 1. Geometric de Sitter closure

For spatially flat FLRW,

\[
\rho_{\rm eff}=3M_{\rm Pl}^2H^2,
\]

\[
p_{\rm eff}
=
-M_{\rm Pl}^2(2\dot H+3H^2).
\]

At

\[
\dot H=0,
\]

one obtains

\[
\boxed{
p_{\rm eff}=-\rho_{\rm eff}.
}
\]

Thus

\[
w_{\rm eff}=-1.
\]

The de Sitter event/apparent horizon radius is

\[
\boxed{
L=H^{-1}.
}
\]

Therefore

\[
\boxed{
HL=1.
}
\]

No dimensionless coefficient is required for this relation once de Sitter is selected.

---

## 2. Horizon-energy normalization and the HDE coefficient

Use the standard holographic form

\[
\rho_X
=
3c^2M_{\rm Pl}^2L^{-2},
\]

with

\[
M_{\rm Pl}^2=\frac{1}{8\pi G}.
\]

The bulk energy inside a sphere of radius \(L\) is

\[
E_X
=
\rho_X V
=
3c^2M_{\rm Pl}^2L^{-2}
\frac{4\pi L^3}{3}.
\]

Therefore

\[
\boxed{
E_X
=
\frac{c^2L}{2G}.
}
\]

For a flat FLRW apparent horizon, the Misner-Sharp energy at the horizon is

\[
\boxed{
E_{\rm MS}
=
\frac{L}{2G}.
}
\]

If the horizon sector saturates the geometric energy at the asymptotic de Sitter fixed point,

\[
E_X=E_{\rm MS},
\]

then

\[
c^2=1.
\]

Taking the positive-density branch,

\[
\boxed{
c=1.
}
\]

This is equivalent to the Friedmann saturation condition

\[
\rho_X
=
3M_{\rm Pl}^2H^2
\]

with

\[
L=H^{-1}.
\]

### Result 046A

Under the explicit assumptions

1. de Sitter causal fixed point;
2. \(L=H^{-1}\);
3. the horizon/HDE sector saturates the total geometric energy at that fixed point;

one obtains

\[
\boxed{
c=1
}
\]

without fitting a continuous coefficient.

This is a **conditional derivation**, not yet a derivation that the universe must select de Sitter or that HDE is the correct microscopic description.

## 3. Horizon thermodynamic consistency

For a de Sitter horizon,

\[
A=4\pi L^2,
\]

\[
S_H=\frac{A}{4G}
=
\frac{\pi L^2}{G},
\]

and

\[
T_H=\frac{1}{2\pi L}.
\]

Hence

\[
\boxed{
T_HS_H
=
\frac{L}{2G}.
}
\]

This equals the apparent-horizon Misner-Sharp energy,

\[
T_HS_H=E_{\rm MS}.
\]

For the HDE bulk energy,

\[
E_X
=
\frac{c^2L}{2G},
\]

so the same saturation condition can be written

\[
E_X=T_HS_H
\]

and again gives

\[
c=1.
\]

Important caveat: \(E=TS\) is not a universal thermodynamic identity for arbitrary dynamical cosmologies. Here it is used only as a de Sitter/apparent-horizon saturation consistency check, where the geometric energies coincide.

\[

-

\[
HL=1,
\]

\[
\boxed{
w_X=-1.
}
\]

Equivalently, using the standard form

\[
w_X

the dark-energy-dominated fixed point

\[
\Omega_X=1,
\qquad
c=1
\]

gives

\[
\boxed{
w_X=-1.
}
\]

Thus positive horizon-sector energy density and negative pressure arise together from the global causal fixed point.

For an adiabatic creation-pressure radiation fluid, the global de Sitter fixed point fixes the dimensionless creation ratio:

\boxed{

}
\]

Again, this is a fixed-point consistency result. It does not yet derive the microscopic particle-production law away from the fixed point.

## 7. Is this a new prediction?

Not yet.

Each element has established prior art:

- de Sitter has \(w=-1\);
- apparent-horizon thermodynamics is equivalent to Friedmann dynamics in Einstein gravity;
- HDE uses \(\rho_X=3c^2M_{\rm Pl}^2L^{-2}\);
- \(c=1\) is the de Sitter boundary of standard future-event-horizon HDE;
- adiabatic particle creation gives \(p_c=-(\rho+p)\Gamma/(3H)\);
- \(\Gamma=3H\) is the de Sitter creation fixed point.

Therefore the closure triangle is a useful synthesis, but not yet an independent LTG law.

The genuinely new requirement would be to derive

\[
\dot H\to0
\]

or an equivalent global causal selection rule from null geometry itself, rather than assuming the de Sitter endpoint.

## 8. Current observational note

Recent late-time HDE fits using DESI DR2, supernovae, cosmic chronometers and growth data have reported an HDE parameter close to unity for at least one combined late-time dataset, for example

\[
c\simeq1.01
\]

with an uncertainty of order \(0.07\).

This is numerically compatible with the \(c=1\) de Sitter boundary in that analysis.

However:

1. other dataset combinations and earlier CMB-inclusive analyses can prefer substantially different \(c\);
2. observational proximity to \(c=1\) does not establish the causal-closure derivation;
3. the HDE model itself is prior art.

Therefore this is a consistency observation, not evidence for LTG.
