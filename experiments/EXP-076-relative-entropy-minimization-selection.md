# EXP-076 — Can relative-entropy minimization select cosmological dynamics?

## Objective

EXP-074 found the exact quantum-information residual

\[
\mathfrak D
=
\frac{\tau_c\Delta Q_{\rm mod}}{\hbar}
-
\Delta\mathcal N
=
\frac{D(\rho\Vert\sigma)}{2\pi}
\ge0.
\]

Test whether the simplest possible selection principle,

\[
\boxed{
\text{minimize }D(\rho\Vert\sigma),
}
\]

can select the cosmological background, vacuum scale, or LTG trajectory without additional input.

---

## 1. Mathematical minimum

Quantum relative entropy satisfies

\[
D(\rho\Vert\sigma)\ge0,
\]

with equality if and only if

\[
\boxed{
\rho=\sigma
}
\]

on the relevant algebra/support.

Therefore the unconstrained minimum is simply

\[
\boxed{
D_{\min}=0.
}
\]

This gives entanglement/modular equilibrium.

---

## 2. First-order gravitational meaning

For small causal diamonds, entanglement-equilibrium constructions impose stationarity of generalized entropy at fixed geometric data.

Combined with the entanglement first law,

\[
\delta S=\delta\langle K\rangle,
\]

this reproduces linearized Einstein/semi-classical gravitational constraints under the appropriate assumptions.

Therefore

\[
D\to0
\]

as a local equilibrium criterion maps directly onto established entanglement-equilibrium gravity.

### Result 076A

Relative-entropy minimization supplies a natural local equilibrium principle, but this is prior art.

---

## 3. Does the minimum fix Lambda?

No.

Consider a family of reference equilibrium states

\[
\sigma_H
\]

associated with different maximally symmetric background curvatures / causal scales.

For each allowed member of the family,

\[
D(\sigma_H\Vert\sigma_H)=0.
\]

Thus the minimum value is degenerate along the family.

The statement

\[
D=0
\]

does not distinguish

\[
H_1
\]

from

\[
H_2.
\]

This is the quantum-information version of the scale-selection gap already found in:

- EXP-049 horizon entropy;
- EXP-050 null focusing;
- EXP-051 causal diamonds;
- EXP-053 information capacity;
- EXP-059 early-boundary conjugacy.

### Result 076B

\[
\boxed{
\text{relative-entropy minimization does not select the absolute cosmological scale.}
}
\]

---

## 4. Constrained minimum

A nontrivial result can arise only if one specifies constraints such as:

- fixed conserved charges;
- fixed total modular energy;
- fixed topology/flux;
- fixed Hilbert-space dimension;
- fixed global boundary data;
- a microscopic Hamiltonian.

Then the selected equilibrium state depends on those data.

Therefore a proposed minimization law without specifying the constraints is incomplete.

---

## 5. Does it select an LTG trajectory N(a)?

No.

At each time one can define a local reference state adapted to the instantaneous background.

Local minimization then produces an equilibrium condition at that instant but does not supply the equation that tells the reference scale how to move from one time slice to the next.

Thus

\[
D=0
\]

is a state condition, not a complete cosmological evolution law.

The causal/quantum part of the desired LTG law is now largely identified:

\[

The remaining genuinely new ingredient must be a **global constraint on the family of reference states**, not another local entropy principle.

The second layer remains open.
