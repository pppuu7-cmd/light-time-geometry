# EXP-015 — Proper-time fraction as hidden-pressure fraction

## Objective

Connect the original SR complementarity

\[
\left(\frac{v}{c}\right)^2+
\left(\frac{d\tau}{dt}\right)^2=1
\]

with the 5D null-lift stress tensor, and test whether the mass/proper-time component has a direct geometrical meaning beyond a kinematic reparameterization.

The result below is formulated for a kinetic/eikonal ensemble of 5D massless modes, where the stress tensor is built from null momenta.

## 1. 5D null dispersion relation

Use an orthonormal frame for

\[
dS_5^2=-c^2dt^2+a(t)^2d\mathbf{x}^2+b(t)^2d\psi^2.
\]

Let

- `p` be the magnitude of the physical 3-momentum in visible space;
- `q` be the physical momentum along the hidden direction.

A 5D massless excitation satisfies

\[
\boxed{
E^2=p^2c^2+q^2c^2.
}
\]

The 4D observer identifies

\[
\boxed{mc=|q|.}
\]

Hence

\[
\boxed{
E^2=p^2c^2+m^2c^4.
}
\]

## 2. Velocity/proper-time decomposition

For the 4D effective particle,

\[
\frac{pc}{E}=\frac{v}{c},
\qquad
\frac{mc^2}{E}=\frac{d\tau}{dt}.
\]

Therefore

\[
\boxed{
\frac{p^2c^2}{E^2}
+
\frac{q^2c^2}{E^2}
=1
}
\]

is exactly

\[
\boxed{
\left(\frac{v}{c}\right)^2+
\left(\frac{d\tau}{dt}\right)^2=1.
}
\]

In the 5D picture the two terms are simply the fractions of the null momentum norm carried in the visible and hidden spatial directions.

## 3. Stress tensor of an isotropic visible ensemble

For a kinetic ensemble with number density `N` and common energy scale `E`, the energy density is

\[
\rho=NE.
\]

For an isotropic distribution in the three visible spatial directions,

\[
P=\frac{N c^2p^2}{3E}.
\]

The pressure along the hidden direction is

\[
P_\psi=\frac{N c^2q^2}{E}.
\]

Divide by `rho`:

\[
\boxed{
\frac{3P}{\rho}=\frac{p^2c^2}{E^2}
=\left(\frac{v}{c}\right)^2
}
\]

and

\[
\boxed{
\frac{P_\psi}{\rho}=\frac{q^2c^2}{E^2}
=\frac{m^2c^4}{E^2}
=\left(\frac{d\tau}{dt}\right)^2.
}
\]

Therefore

\[
\boxed{
\frac{3P+P_\psi}{\rho}=1.
}
\]

This is the pressure-space version of the original LTG complementarity relation.

## 4. 5D tracelessness and the 4D mass trace

For a classical null-particle/eikonal ensemble,

\[
T^{A}{}_{A}
=-\rho+3P+P_\psi=0.
\]

Hence the effective 4D trace is

\[
T^{\mu}{}_{\mu}
=-\rho+3P
=-P_\psi.
\]

Thus

\[
\boxed{
T_{(4)}=-P_\psi.
}
\]

Using the result above,

\[
\boxed{
T_{(4)}
=-\rho\left(\frac{d\tau}{dt}\right)^2
=-\rho\left(\frac{mc^2}{E}\right)^2.
}
\]

This gives a direct geometrical interpretation of the 4D trace generated by effective mass: it is the negative of the stress carried in the hidden direction.

## 5. Limiting cases

### Visible radiation / zero mode

For `q=0`,

\[
m=0,\qquad d\tau/dt=0,
\]

and

\[
3P=\rho,\qquad P_\psi=0,
\qquad T_{(4)}=0.
\]

### 4D massive particle at rest

For `p=0`,

\[
E=mc^2,\qquad d\tau/dt=1,
\]

and

\[
P=0,\qquad P_\psi=\rho,
\qquad T_{(4)}=-\rho.
\]

Thus, in this null-lift kinetic picture, going from 4D radiation to 4D matter corresponds to transferring the stress fraction from visible spatial propagation into hidden-direction momentum.

## 6. Reinterpretation of EXP-014

For the process

\[
0+0\rightarrow n+(-n),
\]

the initial zero modes have

\[
P_\psi=0.
\]

The produced `+n` and `-n` modes carry equal and opposite hidden momentum, so the **net hidden momentum remains zero**, but the hidden pressure is positive because pressure depends on the square of momentum:

\[
(+q)^2+(-q)^2>0.
\]

Therefore pair production can create

\[
\boxed{P_\psi>0}

without violating

\[
\boxed{\sum p_\psi=0}.
\]

This distinction is essential: conserved hidden momentum can vanish globally while hidden stress/pressure becomes nonzero.

## 7. Direct coupling to 5D expansion

For the homogeneous anisotropic metric

\[
dS_5^2=-c^2dt^2+a(t)^2d\mathbf{x}^2+b(t)^2d\psi^2,
\]

define

\[
H=\dot a/a,
\qquad
H_b=\dot b/b.
\]

For flat spatial sections, the 5D Einstein equations give the Hamiltonian constraint

\[
\boxed{
3H^2+3HH_b=\kappa_5^2\rho.
}
\]

The hidden-direction pressure equation can be written

\[
\boxed{
-3\dot H-6H^2=\kappa_5^2P_\psi.
}
\]

Using

\[
P_\psi
=\rho\left(\frac{d\tau}{dt}\right)^2,
\]

we obtain

\[
\boxed{
\dot H
=-2H^2
-\frac{\kappa_5^2\rho}{3}
\left(\frac{d\tau}{dt}\right)^2.
}
\]

This equation is frame/background specific and should not be confused with the observed 4D Einstein-frame Friedmann equation. Nevertheless, within the simple 5D geometry it provides the most direct relation found so far between the effective proper-time fraction and visible expansion dynamics.
