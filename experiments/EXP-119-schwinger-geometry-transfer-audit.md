# EXP-119 — What the exact 2D Schwinger-model analogue does and does not establish

## Objective

Audit the strongest analytic precedent used to motivate a nonlocal topological finite-size response in real QCD.

Urban and Zhitnitsky studied the massive Schwinger model on a two-torus and in curved two-dimensional spacetime.

Determine whether this controlled analogue fixes the four-dimensional de Sitter geometry-transfer coefficient.

---

## 1. Controlled positive result

The two-dimensional model is exactly or nearly exactly tractable and contains the Kogut-Susskind topological ghost analogue.

The analysis finds a departure from the infinite flat-space vacuum that scales as

\[
\boxed{
\Delta E\sim\frac1L
}
\]

on a torus of linear size \(L\), despite the physical spectrum being massive.

This supplies a concrete counterexample to the statement

> every finite-size correction in a gapped gauge theory must be exponentially small.

### Result 119A

\[
\boxed{
\text{non-dispersive topological sectors can produce power-law
infrared sensitivity in a controlled model}.
}
\]

This remains genuine support for the qualitative LTG/QCD mechanism.

---

## 2. Curved-space analysis exists but does not solve the 4D coefficient

The same work constructs the Schwinger/Kogut-Susskind description on curved 2D backgrounds.

It emphasizes that the topological/ghost sector is sensitive to deviation from Minkowski geometry.

However the paper also states explicitly that in four-dimensional strongly coupled QCD the corresponding calculations cannot be done explicitly with the same control.

Thus the 2D result establishes the **possibility and scaling mechanism**, not a universal numerical map

\[
\boxed{
\kappa_{\rm box}^{2D}
\longrightarrow
\kappa_{\rm dS}^{4D}.
}
\]

---

## 3. Topology and curvature are not interchangeable coefficients

Even within two dimensions, the observables depend on:

- torus moduli;
- topology;
- boundary conditions;
- conformal factor / curved background;
- fermion mass and gauge coupling.

Therefore the coefficient of a torus \(1/L\) term is not automatically equal to the coefficient of a curvature-induced term on another manifold.

### Result 119B

The controlled toy model does not justify setting

\[
\boxed{
{\cal T}_{\rm geom}=1
}
\]

in

\[
\kappa_{\rm dS}
=
{\cal T}_{\rm geom}\kappa_{\rm box}.
\]

---

## 4. Strongest justified transfer from 2D to 4D

The robust lesson is structural:

\[
\boxed{
\text{topological contact sector}
\Rightarrow
\text{possible non-exponential sensitivity to global geometry}.
}
\]

The unjustified stronger lesson would be:

\[
\boxed{
\text{the same coefficient must appear in physical 4D QCD on de Sitter}.
}
\]

The latter remains unproven.

---

## 5. Combined with EXP-114

EXP-114 showed that a leading term

\[
H\Lambda_{\rm QCD}^3
\]

cannot come from an ordinary local analytic curvature expansion.

EXP-119 shows that the 2D toy model supplies a plausible mechanism by which this local-EFT expectation can fail: a non-dispersive topological sector with global sensitivity.

Therefore the branch is logically coherent:

\[
\boxed{
\text{local EFT forbids linear }H
}
\]

while

\[
\boxed{
\text{controlled topological toy models permit power-law global sensitivity}.
}
\]

But the physical-4D bridge remains the missing theorem.
