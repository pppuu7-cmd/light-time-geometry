# EXP-121 — Observable diagnostics and risks of the covariant square-root-curvature branch

## Objective

Assess the minimal covariant branch of EXP-120 as a modified-gravity model rather than only as a de Sitter algebraic construction.

The model is

\[
\boxed{
f(R)=R-2\alpha\sqrt R.
}
\]

---

## 1. Effective Planck factor

Metric \(f(R)\) gravity has

\[
\boxed{
F(R)
\equiv
f_R
=
1-\frac{\alpha}{\sqrt R}.
}
\]

At high curvature,

\[
R\gg\alpha^2,
\]

\[
\boxed{
F\to1.
}
\]

Thus the model approaches GR in dense/high-curvature environments.

---

## 2. Late de Sitter point

EXP-120 found

\[
\sqrt{R_*}=3\alpha.
\]

Therefore

\[
\boxed{
F_*
=
1-\frac13
=
\frac23.
}
\]

The effective gravitational normalization at the asymptotic cosmological fixed point is therefore order-unity different from the high-curvature GR normalization.

### Result 121A

\[
\boxed{
\text{the minimal square-root branch predicts substantial late-time Planck-mass running}.
}
\]

It is not a perturbatively tiny deformation of \(\Lambda\)CDM.

---

## 3. Scalaron stability scale

For

\[
f_{RR}
=
\frac{\alpha}{2R^{3/2}},
\]

the scalaron mass is

\[
m_s^2
=
\frac{F}{3f_{RR}}
-
\frac{R}{3}.
\]

At the de Sitter point,

\[
\boxed{
m_s^2
=
R_*
=
12H_*^2.
}
\]

Hence

\[
\boxed{
m_s
=
\sqrt{12}\,H_*.
}
\]

This is a cosmological-range scalar degree of freedom rather than a heavy decoupled correction.

---

## 4. General curvature-dependent scalaron mass

For arbitrary positive curvature,

\[
m_s^2
=
R
\left[
\frac{2\sqrt R}{3\alpha}
-1
\right].
\]

Therefore

\[
m_s^2>0
\]

when

\[
\boxed{
\sqrt R>\frac32\alpha.
}
\]

The de Sitter point satisfies this comfortably.

For the cosmological trajectory to remain tachyon-free, it should stay in the branch above this threshold.

---

\[
m_s^2

### Result 121B

\[
\boxed{
R\uparrow
\Rightarrow
F\to1,
\quad
m_s/H_{\rm local}\uparrow.

A detailed Solar-System/chameleon calculation is still required.

## 6. Gravitational-wave propagation

In metric \(f(R)\) gravity the tensor propagation speed remains luminal, but the varying effective Planck mass modifies the GW friction/amplitude.

Schematically,

\[
\boxed{
\frac{d_L^{GW}(z)}
{d_L^{EM}(z)}
=
\sqrt{
\frac{F(0)}{F(z)}
}
}
\]

for the usual Jordan-frame normalization.

Because

\[
F(z)\to1
\]

at sufficiently high curvature/redshift while the late branch tends toward

\[
F\to2/3,
\]

the model can generate an order-non-negligible standard-siren distance effect.

### Result 121C

Standard sirens give an independent test that does not rely on the QCD finite-volume interpretation.

## 7. Comparison to viable f(R) phenomenology

Modern viable \(f(R)\) models are engineered to remain close to the GR/\(\Lambda\)CDM limit over the observationally probed regime while still accelerating at late times.

Current and near-future:

- large-scale structure;
- weak lensing;
- DESI/BAO;
- CMB;
- standard sirens;

are sensitive to \(F(R)\), \(F_{RR}\), scalaron dynamics and modified GW damping.

The asymptotic value

\[
F_*=2/3
\]

therefore represents a strong phenomenological target, not a hidden small correction.

## 8. Radiation-era caveat

The square-root action is nonanalytic at

\[
R=0.
\]

An exactly radiation-only GR background has

\[
R=0.
\]

Thus EXP-120 should be regarded as a **late-time effective branch**, unless a microscopic completion regularizes the action near \(R=0\).

In the real universe, matter trace and other sectors make \(R\) nonzero over much of the history, but this does not remove the theoretical nonanalyticity.

### Result 121D

\[
\boxed{
\text{the minimal }\sqrt R\text{ action is not yet a complete all-epoch cosmology}.
}
\]

## 9. Comparison with the ghost-fluid branch

### Fluid closure

Advantages:

- simple;
- directly connects \(\rho_X\propto H\).

Problems:

- rigid
  \[
  w_X=-1/(2-\Omega_X);
  \]
- positive local CPL slope;
- negative adiabatic \(c_a^2\) in the naive perfect-fluid interpretation.

### Square-root-curvature closure

Advantages:

- covariant;
- no manual infrared length;
- stable de Sitter scalaron;
- GR recovered at high curvature.

Problems:

- nonanalytic at \(R=0\);
- extra scalar gravity degree of freedom;
- large late-time change in \(F\);
- must pass growth, lensing and standard-siren constraints;
- QCD derivation of the \(\sqrt R\) coefficient remains absent.
