## EXP-049 — horizon entropy stationarity

For flat FLRW,

\[
R_A=H^{-1},
\qquad
S_A=\frac{\pi}{GH^2}.
\]

Thus

\[
\dot S_A
=
-\frac{2\pi}{G}\frac{\dot H}{H^3}.
\]

Using

\[
\dot H=-4\pi G(\rho+p),
\]

gives

\[
\dot S_A
=
\frac{8\pi^2}{H^3}(\rho+p).
\]

Hence the NEC implies

\[
\dot S_A\ge0.
\]

If a finite nonzero horizon scale exists asymptotically,

\[
H\to H_*>0,
\]

and entropy saturates,

\[
\dot S_A\to0,
\]

then

\[
\dot H\to0,
\qquad
w_{\rm eff}\to-1.
\]

So entropy stationarity can select the vacuum-like pressure endpoint.

But

\[
S_{\rm dS}=\frac{\pi}{GH_*^2}
\]

does not select the numerical value of \(H_*\).

**Classification: endpoint PASS / scale-selection FAIL.**

## EXP-050 — null Raychaudhuri lambda-blindness

For null \(k^\mu\),

\[
R_{\mu\nu}k^\mu k^\nu
=
8\pi G T_{\mu\nu}k^\mu k^\nu.
\]

The cosmological-constant term vanishes because

\[
g_{\mu\nu}k^\mu k^\nu=0.
\]

Therefore a vacuum stress

\[
T_{\mu\nu}^{\rm vac}
=
-\rho_{\rm vac}g_{\mu\nu}
\]

has

\[
T_{kk}=0
\]

for every value of \(\rho_{\rm vac}\).

Exact de Sitter,

\[
R_{\mu\nu}=3H^2g_{\mu\nu},
\]

and Minkowski both satisfy

\[
R_{kk}=0.
\]

Thus local null focusing cannot distinguish \(H=0\) from \(H>0\) inside the Einstein-vacuum family and cannot fix \(\Lambda\).

**Classification: analytic null-blindness no-go.**
